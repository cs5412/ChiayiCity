第一次開啟需要幾秒鐘
1選擇任務
點選你這次要回報的行為。每個任務的規則與可得點數不同。
2減量作為類型
請選擇你這次做的是哪一種。捐出或交換物品、購買二手物、把壞掉的東西修好都算。
2這次自備了幾件？
每一件算 1 點。例如帶了 2 個環保杯＋1 個購物袋，就是 3 點。
請務必讓每一件都清楚入鏡。審核時會核對照片與數量， 若填寫 5 件但照片只看得出 3 件，將以實際看得到的 3 件計點， 不會退件，但也不會補回差額。
若一張拍不下，可將第二張照片也用來補拍其餘品項。
目前 0 件・可得 0 點
填寫的件數需與照片相符，審核人員會依照片實際可辨識的數量給點。
3店家編號
請看店家櫃台的認證標章貼紙，上面有三位數編號。掃 QR Code 會自動帶入。

補充說明（選填）
照片看不清楚、或有特殊情況想讓審核人員知道，可以寫在這裡。
